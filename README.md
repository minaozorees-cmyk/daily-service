# الخدمة اليومية

تطبيق ويب تقدّمي (PWA) عربي RTL لخدام كنيسة العذراء مريم والشهيد مارجرجس ببني خالد: خطة روحية يومية (قراءة، تأمل، صلاة، خدمة)، ومسابقة أسبوعية، ومشاركات، ولوحة إدارة.

> ## ⚠️ يحتوي على حسابات تجريبية مكشوفة — للاستخدام التجريبي فقط.
> **لا تضع أي بيانات حقيقية في هذا الريبو حتى v1.2.**
>
> - الحسابات التجريبية وكلمات مرورها مكتوبة نصًّا داخل `js/app.js` والريبو عام، فهي معروفة لكل من يفتحه.
> - لا تستعمل كلمات مرور هذه الحسابات في أي مكان آخر.
> - البيانات في هذه النسخة محلية على كل جهاز (`localStorage`) ولا تُرسل لأي سيرفر.
> - تُحذف الحسابات التجريبية نهائيًّا في v1.2 عند دخول Supabase.

## الحالة: v1.0

تقسيم النموذج الأولي `v12` (ملف HTML واحد) إلى ملفات، وإضافة هيكل PWA (قابل للتثبيت ويعمل بدون إنترنت). **السلوك والتصميم والنصوص كما هي في v12** دون تغيير. النموذج الأولي v12 خارج الترقيم، ولا يدخل هذا الريبو.

| الإصدار | المحتوى |
|---|---|
| **v1.0** | تقسيم + هيكل PWA + حسابات تجريبية (جسر) |
| v1.1 | Supabase + Auth + موافقة المسؤول |
| v1.2 | المزامنة + طابور الرفع + حذف الحسابات التجريبية |
| v1.3 | النتائج المباشرة + استيراد بيانات v12 (localStorage → Supabase) |
| v1.4 | استيراد JSON + إشعارات Push + تصدير Excel |

## الهيكل

```
index.html          الصفحة (محتواها كما في v12 + سطر الإصدار)
css/app.css         كل التنسيقات (مطابق بالبايت لـ v12)
js/app.js           كل المنطق (مطابق بالبايت لـ v12)، سكربت عادي بلا modules
js/version.js       رقم الإصدار APP_VERSION
js/pwa.js           تسجيل الـService Worker + سطر الإصدار + لون شريط الحالة
sw.js               الـService Worker (استراتيجيات الكاش)
manifest.json       بيانات التثبيت
icons/              أيقونات PNG (192 · 512 · maskable · apple-touch)
tests/              اختبار الدخان + لقطات الشاشة
```

## التشغيل محليًّا

يحتاج خادمًا ثابتًا (الـService Worker لا يعمل من `file://`):

```
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## الاختبار

```
npm i -D playwright && npx playwright install chromium
node tests/v1-smoke.browser.mjs
```

اختياريًّا لفحص التطابق بالبايت مع v12: `V12=/مسار/daily_service_v12.html node tests/v1-smoke.browser.mjs`.
