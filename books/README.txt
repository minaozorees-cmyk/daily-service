مجلد النصوص (v1.4) — نصوص تجريبية مؤقتة (يوحنا ١٥ + صلاتان من الأجبية) نُقلت من BIBLE_DATA.
لاحقًا تُستبدل بنصوص «خدمة إعدادي» بنفس الشكل.

الشكل:
  index.json  → { "rev": N, "books": [ { id, kind: "bible"|"agpeya", title, short, file, rev, sections: [ { n, title } ] } ] }
  <id>.json   → { id, title, kind, rev, chapters: { "<n>": { title, verses: [ "نص الآية", ... ] } } }
القواعد:
  • id هو نفسه معرّف السفر (slug) في جدول books في Supabase (مثل john / agpeya)، و n هو رقم القسم (الأصحاح) نفسه.
  • عند تعديل أي نص: ارفع rev في ملف السفر وفي مدخله في index.json (وإلا يبقى الكاش القديم على الأجهزة).
  • ملف جديد لا يحتاج رفع VERSION في sw.js: الملفات تُحمَّل عند الطلب (lazy) وتُخزَّن في كاش مستقل ds-books-v1.
  • النصوص تُعرض كنص عادي (تُهرَّب HTML)، فلا تضع وسوم HTML داخل الآيات.
  • الملفات عامة في الريبو: حجب الأصحاحات غير المفتوحة في الواجهة تجربة مستخدم فقط وليس أمانًا.
